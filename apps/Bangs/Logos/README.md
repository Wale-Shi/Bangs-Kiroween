# CLI logos

Each logo is a trademark of its owner and is used here only to show which CLI a session belongs to.

- From [lobe-icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg@1.102.0`, MIT), with `width`/`height`
  set to 64 instead of `1em`: Claude Code (`claudecode-color`), Codex (`openai`, the ChatGPT mark, saved as `codex.svg`), Gemini CLI (`geminicli-color`), Qwen
  (`qwen-color`), OpenCode (`opencode`), GitHub Copilot (`githubcopilot`), Cursor (`cursor`), Kiro (`kiro`), CodeBuddy
  (`codebuddy`), Qoder (`qoder-color`), pi (`pi`) and Hermes Agent (`hermesagent`). Plain marks are used where the colour version sits on a tile.
- Factory (Droid): https://factory.ai/favicon.svg with its black background square and dark-mode style removed.
- omp (oh-my-pi): `assets/icon.svg` from https://github.com/can1357/oh-my-pi, its white strokes drawn in `currentColor`.

`currentColor` is filled in at runtime: white on the notch, black on light backgrounds, or the CLI's colour for Kiro and
CodeBuddy.
