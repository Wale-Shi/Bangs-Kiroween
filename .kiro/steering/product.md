# Bangs for Kiroween

Bangs already displays live agent activity in a native macOS panel. The Skeleton Crew entry also needs a separate terminal app for reviewing a completed session from a JSON Lines file. Both must consume one small, reusable Swift event format. Keep the shared template independent of AppKit, sockets and machine-specific configuration. Keep existing Bangs hooks compatible.

Use invented session data in samples and tests. Display only normalized event labels, agent names and opaque session labels by default. Do not print prompts, tool input, environment variables, local paths or terminal control characters. Run the CLI against the sample and test malformed and out-of-range input. The source and judge instructions are public. Use English for all new judging material.
